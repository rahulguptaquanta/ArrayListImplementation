# ArrayList Implementation

A Java console application demonstrating how to store and manipulate strings using `ArrayList`.

## Features

- Add strings to the list
- Remove a string from the list
- Search for a string and display its index
- Display all items using iteration
- Handle invalid menu choices and missing items

## Project Structure

```text
ArrayListImplementation/
├── src/
│   └── com/
│       └── internship/
│           └── arraylist/
│               └── ArrayListDemo.java
├── .gitignore
└── README.md
```

## Requirements

- Java JDK 8 or later

## Compile and Run

From the project root, run:

```bash
javac -d out src/com/internship/arraylist/ArrayListDemo.java
java -cp out com.internship.arraylist.ArrayListDemo
```
